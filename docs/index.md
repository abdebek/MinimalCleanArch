# MinimalCleanArch docs

This folder describes the repository as the code exists today. It is a Clean Architecture toolkit, not a single business product. The runnable systems are the sample API and the apps generated by `dotnet new mca`.

## What this is not

These pages do not redesign the system. If a README and the source disagree, the source wins.

This is DDD inspired, not strict DDD. Shared databases, generic repositories, and anemic Identity models are documented as they are.

## Leftover, not live

| Path | What it is |
|---|---|
| `docs/MinimalCleanArch.Docs/` | DocFX project whose `Program.cs` prints `Hello, World!`. Not the live documentation host. Ignore its `bin/` and `obj/`. |
| `src/*/bin`, `src/*/obj` | Build output. |
